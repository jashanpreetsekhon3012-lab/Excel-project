Retail Sales Dashboard – Excel
 Project Overview

The **Retail Sales Dashboard** is an interactive data analysis and visualization project created using **Microsoft Excel**. The purpose of this project is to analyse retail sales data and convert raw data into meaningful business insights through an interactive dashboard.

The project includes data collection, data organization, data cleaning, preparation, Pivot Tables, Pivot Charts, slicers, and dashboard development.

The dashboard helps analyse sales performance based on **Region, Category, Customer Segment, Quantity, Profit, and Discount**. It provides a simple and interactive way to understand business performance and identify important sales patterns.

 Objectives

The main objectives of this project are:

- To organize raw retail sales data into a structured dataset.
- To clean and prepare the data for analysis.
- To identify and handle incorrect, missing, or inconsistent data.
- To analyse sales performance across different regions and categories.
- To analyse profit, quantity, and discount patterns.
- To compare sales performance across customer segments.
- To create interactive visualizations using Excel.
- To develop a user-friendly dashboard for business analysis.
- To generate meaningful insights that can support data-driven decision-making.

 Dataset

The dataset contains retail sales transaction information. The data was organized into rows and columns so that it could be easily analysed using Microsoft Excel.

Each row represents a sales record, while each column represents a specific attribute related to the transaction.

Main Columns Used

| Column | Description |
| Date | Date on which the sale took place |
| Region | Geographical region of the sale |
| Category | Product category |
| Sub-Category | Specific type of product within a category |
| Sales | Total sales/revenue generated |
| Quantity | Number of units sold |
| Profit | Profit generated from the sale |
| Discount | Discount offered on the transaction |
| Segment | Customer segment |

# 🧹 Data Cleaning and Preparation

Before creating the dashboard, the dataset was carefully reviewed and cleaned in Microsoft Excel.

Data cleaning was important because incorrect or inconsistent data can affect calculations, Pivot Tables, charts, and the final business insights.

### Data Cleaning Steps

The following steps were performed:

### 1. Data Organization

The raw data was arranged into proper rows and columns. Each column was given a clear heading so that Excel could correctly recognize and analyse the information.

### 2. Checking Missing Values

The dataset was checked for blank or missing values. Wherever necessary, missing or incomplete values were reviewed and handled appropriately.

### 3. Removing Duplicate Records

Duplicate records were checked to prevent the same transaction from being counted more than once.

### 4. Standardizing Data

Inconsistent entries were reviewed and standardized. For example, region, category, and segment names were checked to ensure that similar values were represented consistently.

### 5. Correcting Data Types

The appropriate data type was applied to each column.

For example:

- Date column → Date format
- Sales → Number/Currency
- Profit → Number/Currency
- Quantity → Number
- Discount → Number/Percentage
- Region → Text
- Category → Text
- Segment → Text

### 6. Checking Numerical Values

Sales, quantity, profit, and discount columns were reviewed to identify incorrect or unusual values that could affect the analysis.

### 7. Preparing Data for Analysis

After cleaning, the dataset was structured in a format suitable for creating Pivot Tables and Pivot Charts.

# Data Analysis Process

The overall process followed in this project was:

**Raw Data → Data Cleaning → Data Preparation → Pivot Tables → Pivot Charts → Slicers → Interactive Dashboard → Business Insights**

This process helped convert raw transaction-level data into an easy-to-understand visual report.

#  Dashboard Visualizations

The dashboard contains the following major visualizations:

## 1. Sales by Region & Category

This chart compares sales across different regions and product categories.

It helps identify:

- Which region generates higher sales.
- Which product categories perform better.
- Differences in category performance between regions.

This visualization is useful for comparing sales performance at both regional and category levels.

## 2. Sales by Region

This chart shows the total sales generated by each region.

The four regions shown are:

- Central
- East
- South
- West

It provides a quick comparison of regional sales performance and helps identify stronger and weaker markets.

## 3. Profit by Region & Category

This visualization focuses on profit rather than sales.

It helps analyse:

- Profit contribution from different regions.
- Profitability of different product categories.
- Categories that generate higher or lower profit.
- Regional differences in profitability.

This is important because a category with high sales does not always generate the highest profit.

## 4. Quantity by Region

A pie chart is used to show the distribution of total quantity sold across different regions.

It helps answer questions such as:

- Which region sells the highest number of units?
- How is the total quantity distributed?
- Which regions contribute more to overall sales volume?

## 5. Sales by Segment

A doughnut chart shows sales distribution across different customer segments.

The segments include:

- Consumer
- Corporate
- Home Office

This visualization helps understand which type of customer contributes the most to total sales.

## 6. Discount by Region & Category

The line chart shows the pattern of discounts across different regions and categories.

It helps analyse:

- Where higher discounts are being provided.
- How discount levels vary.
- Differences in discount patterns across regions and categories.

Discount analysis can help businesses understand pricing strategies and their possible relationship with sales and profitability.
